# Proyecto Semana 04: Catálogo Interactivo con Filtros y Búsqueda

## Dominio asignado
**E-commerce de libros usados**  
Catálogo interactivo de libros de segunda mano, con información como título, autor, año de publicación, condición física, precio en COP, disponibilidad y calificación.

## Objetivo del proyecto
Crear una aplicación web en React + TypeScript que permita explorar un catálogo de libros usados con las siguientes funcionalidades principales:

- Búsqueda en tiempo real (por título y autor)
- Filtros por categoría y solo disponibles
- Ordenamiento por título (A-Z / Z-A), precio (asc/desc), rating y más recientes
- Renderizado condicional: estado de carga, error, vacío y resultados
- Contador de resultados encontrados
- Tarjetas individuales con badges de condición y disponibilidad
- Limpieza de filtros y búsqueda con un solo botón
- Tipado completo con TypeScript (sin `any`)

## Tecnologías utilizadas
- React 18+
- TypeScript
- Vite (como bundler y servidor de desarrollo)
- pnpm (gestor de paquetes)
- CSS puro (en `App.css`) para estilizado
